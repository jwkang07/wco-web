## 참고 (나무말미)

`nm_dev`의 문서·구현은 **기능 참고용**. WCO 화면을 복제하지 않는다.  
이메일 발송·외부 API는 고객 의견 후이며 나무말미 연동 수준이 목표가 아니다.  
1차 확정: 문의 답은 전화·개별 메일, 관리자는 상태·메모, DB는 Supabase, 단원 동의는 이후.
