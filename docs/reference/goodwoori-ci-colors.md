## 심볼

- 오렌지 두 점 + 다크 그레이 곡선 (「오」「우」, 두 사람이 함께 나아감)
- 워드마크: 사회복지법인 굿피플 / 은평구립우리장애인복지관

## 캐릭터 (참고)

- 우리람이, 오우맨 — 오케스트라 사이트 본문에는 과다 사용 지양, 푸터·어린이 영역 등 선택적

## 우리챔버오케스트라 적용 원칙

- Primary: 오렌지 `#E85A24`
- Text: 다크 그레이 `#262626`
- Surface: 화이트 + 피치 `#FBE8E6`
- 복지관 로고·소속 문구는 CI 규정대로 사용 (`woori_CI.ai`에서 PNG/SVG 추출 후 `public/`에 배치)

## 로고 추출 (개발 시)

1. `woori_CI.ai`를 Illustrator 또는 호환 툴로 열기
2. 심볼·가로형 로고를 PNG(투명) 또는 SVG로보내기
3. `public/brand/goodwoori-logo.png` 등으로 저장
4. 오케스트라 전용 로고가 생기기 전까지는 복지관 로고 + 프로그램명 조합 사용
