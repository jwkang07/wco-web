# 관리자 UI — 셸·레이아웃 가이드

공개 사이트 브랜드 가이드(`UI_GUIDE.md`)와 **분리**된 관리자 콘솔 기준입니다.  
버튼·피드백은 각각 `ADMIN_UI_BUTTON_GUIDE.md` / `ADMIN_UI_UX_GUIDE.md`.

관리자 패널의 **검증된 기능**(셸·메뉴·폼 액션)을 참고하고, 시각·카피는 WCO 관리자 중립 톤으로 맞춘다. 나무말미 화면을 복제하지 않는다.

> 상태: 관리자 앱 코드는 아직 없을 수 있음. 이 문서는 **구현 전에 고정하는 계약**이다. UI는 나중에 바뀌어도 공개/관리자 분리·패턴 F·인라인 피드백 원칙은 유지한다.

---

## 1. 목적·범위

| 항목 | 내용 |
|------|------|
| 경로 | `app/admin/**` (추후 환경변수로 URL 마스킹 가능) |
| 사용자 | 오케스트라·복지관 운영담당자 |
| 할 일 | 콘텐츠 CRUD, 문의 열람·상태·메모, FAQ, 관리자·작업 이력 |
| 하지 않을 일 | 공개 마케팅 셸 복제, 문의 자동 메일 답장, 단원 공개 동의 워크플로(1차 제외) |

### 1차 확정 (운영 합의)

| 주제 | 결정 |
|------|------|
| 문의 답변 | **전화·개별 메일**로 처리. 시스템 자동 답장 없음 |
| 문의 관리 | 목록 열람 + **상태 변경** + **메모** |
| DB·파일 | **Supabase** (PostgreSQL + Storage) |
| 단원 | **CRUD만**. 초상권·공개 동의 기능은 **이후** |
| 문의 개인정보 | 공개 폼에 **동의 체크**는 1차 포함. 동의 문구·보관 기간 문구는 운영 제공 |

1차 콘텐츠 관리: 홈·메뉴별 히어로(이미지·텍스트), 홈 최근공연·보도 노출, 히스토리·공연활동·보도자료, 단원, FAQ, 관리자 계정·작업 이력.

## 2. 정보 구조 (1차 메뉴)

| 메뉴 | 역할 |
|------|------|
| 대시보드 | 최근 문의·미처리 건수 요약 |
| 히어로·홈 | 홈/메뉴별 상단 비주얼·텍스트, 최근공연·보도 노출 |
| 우리활동 | 히스토리 · 공연활동 · 보도자료 |
| 단원 | 프로필 CRUD (동의 플로우는 이후) |
| 문의 | 공연문의 목록 · 상태 · 메모 |
| FAQ | 자주 묻는 질문 |
| 설정 | 관리자 계정 · 작업 이력 |

메뉴명은 구현 시 조정 가능. **목록 → 등록/수정** 흐름은 모든 도메인에서 동일.  
고용 연계(기업·아티스트) CMS는 1차 범위 밖.

## 3. 레이아웃 골격

```
┌──────────────────────────────────────────┐
│ 상단: 로고(작게) · 콘솔명 · 로그아웃        │
├────────┬─────────────────────────────────┤
│ 사이드 │ 페이지 헤더 (제목 + 등록 버튼)     │
│ 내비   ├─────────────────────────────────┤
│        │ 필터/검색 (목록) 또는 폼 본문      │
│        │ …                                 │
│        │ [패턴 F 액션 바]                  │
└────────┴─────────────────────────────────┘
```

| 규칙 | 내용 |
|------|------|
| 사이드 | 고정 폭, 현재 메뉴 강조는 **글자/배경 중립** (공개 주황 pill 남용 금지). 활성은 다크 텍스트 + 연한 배경 |
| 콘텐츠 | `max-w`를 두어 표·폼이 과하게 늘어나지 않게 |
| 테이블 | 헤더 sticky 가능. 빈 행은 `AdminEmptyTableRow` |
| 폼 | 라벨 위 / 필드 아래. `*` = 필수 = 서버·클라이언트 검증 일치 |

## 4. 색·타이포 (관리자 전용)

공개 `wco-*` 마케팅 팔레트를 **그대로 쓰지 않는다.**

| 토큰 | 값 | 용도 |
|------|-----|------|
| 주 버튼 | `#5a554c` | 등록·수정 |
| 텍스트 | `#262626` / `#6B6B6B` | 본문 / 보조 |
| 경계 | `black/10` ~ `black/20` | 구분선·outline |
| 강조(드물게) | `wco-orange` | 링크 hover·배지 정도만. **주 버튼 금지** |
| 배경 | `#f7f7f6` 또는 white | 셸 / 카드 |

폰트: 공개와 동일 **Noto Sans KR**. 관리자에서 `.font-serif` 장식 남용 금지.

---

## 5. 목록·상세 공통

1. 목록 상단 오른쪽: **등록** (주 버튼 스타일 또는 동등)
2. 행 클릭 또는 **수정** → 폼
3. 상세만 있는 화면: 패턴 L `목록으로` + **수정** 진입
4. 이미지는 썸네일 + 교체. 파일 input은 `data-admin-focus`로 포커스 가능하게

단원 사진은 **동의 여부**를 목록/폼에 명시 (미동의면 공개 사이트 비노출).

---

## 6. 인증·보안 (코딩 규칙과 연동)

- 관리자 세션은 서버에서만 검증 (나무말미 HMAC 쿠키 패턴 권장)
- `SUPABASE_SERVICE_ROLE_KEY` 등 시크릿은 서버 전용
- 공개 `SiteHeader` / `PageShell` / `Hero`를 admin 레이아웃에 import하지 않음
